StepJudge + deterministic cache

One step, one verdict — never the whole trace at once. Each bounded step is hashed with SHA-256 and judged by a local Qwen2.5:7b in structured JSON mode. Identical prompts are never paid for twice: memory answers in under 0.1 ms, SQLite in under 2 ms.

  1. a
    Build the canonical prompt

    _build_prompt() packs task goal, step index, agent, recipient, context, action payload, and output state — then strip()-normalizes it so identical steps hash identically.

  2. b
    Two-tier lookup

    get() checks the memory dict, then the prompt_cache table (hash PK, hit/miss counters, WAL durability). Hits also refresh an in-memory copy.

  3. c
    Judge or fall back

    On miss: Qwen2.5:7b via Ollama in JSON mode; if unreachable, the heuristic MockJudge scores 25+ failure signatures (reset to nan, drop table, …). set() persists every fresh verdict.
