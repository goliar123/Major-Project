↳ The three tabs

Pick your starting point

Presets for demos, raw logs for reality, JSON for pipelines.

  1. a
    Curated failure presets

    One-click viva demos: each card shows its environment, turn count, and expected blame + expected step before you run — then POST /attribute proves the engine agrees.

  2. b
    Raw console parser

    Paste a terminal transcript with a task goal; POST /parse/raw_log segments [Sender → Recipient] lines into steps and attributes them in one shot.

  3. c
    Custom JSON payload

    Drop a MultiAgentTrace-shaped document (title, goal, steps) into POST /parse/custom_json — the same door CI pipelines use.
