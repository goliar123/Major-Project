↳ 01 — Engine

Five-stage neuro-symbolic pipeline

Symbolic structure constrains the LLM judge, so evaluation is causal — not vibes. Open the stage deep-dives →

trace.json →1 Budget →2 StepJudge →3 DAG →4 Backward traversal →5 Root vs Symptom →report
causal graph · crash at s14, origin at s7live traversal
information dependency backward traversal (animated) ◉ s7 true root ◉ s14 manifestation
  1. 01Token budgetingSegmentation + context-window manager keeps each judge call inside budget.segmentation.py
  2. 02StepJudgePer-step LLM verdict with a persistent SQLite cache.step_judge.py + cache.py
  3. 03Dependency DAGInformation links between steps and agents.dependency_linker.py
  4. 04Backward traversalTwo-phase walk from manifestation back to origin.backward_traversal.py
  5. 05Root vs symptomIsolates s* from inherited failures via deterministic hashing.SHA256(goal+ctx+action)

↳ 02 — Results

Why it beats monolithic judging

All-at-Once LLM judges blame wherever the crash surfaced. Backward traversal follows causality.

01

Dependency-aware traversal

Visits only causal ancestors Anc(smanifest), cutting noise from unrelated turns.

02

Deterministic caching

SQLite B-tree on SHA-256 prompt hash — same prompt, same verdict, ~1.2 ms, no re-spend.

03
