↳ Why local

Sovereignty is a feature

Failure traces contain proprietary prompts, tool args, and data — shipping them to a vendor API is a non-starter.

  1. a
    Judge on-machine

    Qwen2.5:7b serves structured verdicts (validity, score, anomaly flag, category) through Ollama's OpenAI-compatible endpoint — deterministic temperature, JSON mode, zero egress.

  2. b
    Survive outages

    If the daemon is unreachable, the MockJudge scores the step against 25+ calibrated failure signatures (reset to nan, drop table, …) so diagnosis degrades gracefully instead of failing.

  3. c
    Stay configurable

    Settings expose model selection, the anomaly threshold, and cache backend switching — the same knobs the report's §3 settings view specifies.
