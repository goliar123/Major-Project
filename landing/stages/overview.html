From crash log to named culprit

A multi-agent run collapses at the terminal agent — but the defect was injected silently, turns earlier. This engine refuses to blame the crash site: it budgets tokens, judges every step, links the causal graph, walks it backwards, and isolates the originating root cause. ↳ The problem

Symptom misattribution

Monolithic LLM judges read the whole trace at once and blame wherever the crash surfaced — step-level accuracy under 15%.

When an agent injects an erroneous premise, invalid tool parameter, or unfulfilled schema constraint, the defect propagates silently: downstream agents consume the corrupted context as ground truth until an end-of-chain agent crashes.

The report's canonical example is a financial-audit orchestration: the Writer agent at step 2 mis-formats a data table, the error rides through ratio computation and risk analysis, and the run collapses far downstream. An All-at-Once judge blames the terminal agent — the classic recency bias failure (53.5% who / 14.2% when).

The fix is architectural: decouple local semantic judgement (what did this step do?) from global causal reasoning (how did the fault travel?). Neural networks do the former — Qwen2.5:7b over one step at a time; symbolic graph algorithms do the latter — NetworkX over the dependency DAG.

↳ The pipeline

Five stages, five pages

Packets flow left to right; blame flows right to left. Open any stage for the full working.

end-to-end data flowanimated
forward: data gets smaller and more certain · backward: suspicion travels from symptom to origin
  1. 01 →
    Token budgeting & segmentation

    Heterogeneous logs → normalized ExecutionStep entities under a strict 4,096-token ceiling (60% head / 30% tail).

  2. 02 →
    StepJudge + deterministic cache

    One verdict per step from local Qwen2.5:7b, keyed by SHA256(model‖prompt) — hits return in <2 ms.

  3. 03 →
    Dependency DAG

    NetworkX graph: sequential flow (0.85) + identifier-linked shared state (0.95) + message replies.

  4. 04 →
    Backward traversal

    Transitive ancestor closure of the symptom in O(V+E); peripheral noise pruned away.

  5. 05 →
    Root vs symptom

    Clean-parent invariant isolates s*; 2-D taxonomy + shortest causal chain explain the verdict.
